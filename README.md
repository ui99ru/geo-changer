# GeoChanger

Приложение для Android, которое подменяет GPS-координаты для всех приложений на устройстве.

---

## Как это работает

Выбираешь точку на карте → нажимаешь **«Запустить»** → все приложения начинают видеть выбранные координаты. Нажимаешь **«Остановить»** — GPS возвращается к реальному значению.

Используется стандартный Android API `LocationManager.addTestProvider()` — приложение становится «поставщиком» местоположения и отправляет подставные координаты в систему каждые 100 мс.

## Установка

### Через GitHub Actions (рекомендуется)

1. Перейди во вкладку **Actions** репозитория
2. Открой последний успешный запуск **Build APK**
3. Скачай артефакт `geo-changer-apk` → распакуй zip → установи `geo-changer.apk`

### Сборка из исходников

```bash
git clone https://github.com/ui99ru/geo-changer.git
cd geo-changer
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Требования: JDK 17+, Android SDK с API 34.

---

## Настройка перед первым запуском

Приложению необходимо разрешение на подмену локации. Оно выдаётся вручную в параметрах разработчика:

1. **Включить режим разработчика**
   `Настройки → О телефоне → нажать «Номер сборки» 7 раз`

2. **Назначить приложение**
   `Настройки → Для разработчиков → Выбрать приложение для тестирования позиции → GeoChanger`

Приложение само покажет это диалогом с кнопкой «Открыть параметры разработчика», если разрешение не выдано.

## Использование

| Действие | Результат |
|---|---|
| Тап на карту | Устанавливает маркер в выбранной точке |
| Кнопка **⊕** (справа вверху) | Центрирует карту на реальной геопозиции |
| **«Запустить»** | Все приложения получают выбранные координаты |
| **«Остановить»** | Реальный GPS возобновляется |
| Кнопка «Stop» в уведомлении | Остановка без открытия приложения |

## Технологии

| Компонент | Решение |
|---|---|
| Язык | Kotlin |
| UI | Jetpack Compose |
| Карта | [OSMDroid](https://github.com/osmdroid/osmdroid) (OpenStreetMap) |
| Архитектура | MVVM · ViewModel · StateFlow |
| Фоновая работа | ForegroundService · Kotlin Coroutines |
| Min SDK | Android 8.0 (API 26) |

## Ограничения

- Работает только при включённом режиме разработчика
- Не подменяет локацию в приложениях, использующих аппаратный GPS напрямую (редкость)
- При закрытии приложения сервис продолжает работать — остановить можно из уведомления
